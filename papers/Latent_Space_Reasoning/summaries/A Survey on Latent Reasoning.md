### 研究问题与动机

本文是一篇关于**潜在空间推理（Latent Reasoning/Latent Chain-of-Thought, Latent CoT）** 领域的系统性综述。其核心研究问题是：如何将大语言模型（LLM）的多步推理过程完全迁移到模型的连续隐藏状态空间中执行，从而突破传统显式思维链（CoT）依赖自然语言离散token带来的表达带宽瓶颈？

**动机**：
- 传统显式CoT虽然提升了可解释性和准确性，但自然语言的离散token表示带宽有限（每个token约15 bits），限制了模型的表达范围
- LLM的大部分计算开销实际上发生在潜在空间中，强制使用自然语言约束了模型的推理能力
- 潜在推理无需token层面的监督，可以实现非语言化的推理路径，解锁不依赖自然语言表达的推理策略
- 该方向是当前最前沿推理模型（如DeepSeek-R1、Qwen3等）的底层支撑技术


### 方法与创新（公式用 ）

本文构建了一个全面的潜在推理分类体系，核心方法分为两大类：

**1. 统一数学框架**

定义在时间步 $t$ 和层 $l$ 的激活 $x^{l}_{t} \in \mathbb{R}^d$，以及捕获历史信息的隐藏状态 $S^{l}_{t}$：

**空间变换**（垂直方向，固定时间步内跨层传播）：
$$x^{l+1}_{t+1} = f(x^{l}_{t+1}, g(S^{l}_{t}, x^{l}_{t}))$$

其中 $f$ 表示层间变换函数（如Transformer模块），$g$ 表示历史信息的维护和更新方式。

**激活基方法**（垂直循环，在同一时间步内通过递归计算增加深度）：
$$x^{l+n}_{t} = f( \dots f(f(x^{l}_{t}, g(S^{l}_{t}, x^{l}_{t})), g(S^{l+1}_{t}, x^{l+1}_{t})), \dots, g(S^{l+n-1}_{t}, x^{l+n-1}_{t}))$$

**隐藏状态基方法**（水平循环，通过跨时间步的隐藏状态聚合增加序列容量）：
$$x^{l+1}_{t} = f(x^{l}_{t}, g(S^{l}_{t}, S^{l}_{t-1}, \dots, S^{l}_{t-n}, x^{l}_{t}))$$

**显式CoT与潜在CoT的对比**：
- 显式：$y_{t+1} = \text{Decode}(\text{Transform}(x_t, S_t))$
- 潜在：$z_{t+1} = \text{Transform}(z_t, S_t)$，消除了解码步骤

**2. 扩散模型的潜在更新**

离散更新（掩码基）：
$$x^{l}_{t+1}(i) = \begin{cases} f(x^{l}_{t}(i), \epsilon_t), & m_t(i) = 1 \\ x^{l}_{t}(i), & \text{otherwise} \end{cases}$$

连续更新（噪声基）：
$$x^{l}_{t+1} = f(x^{l}_t, \epsilon_t)$$

带KV-Cache的置信度阈值空间变换：
$$x^{l+1}_{t} = f_{\tau}(x^{l}_{t}, S^{l}_{t}, \epsilon_t)$$

选择性时间缓存更新：
$$S^{l}_{t+1}(i) = \begin{cases} g_{\tau}(x^{l}_{t}(i), S^{l}_{t}(i)), & c^{l}_{t}(i) \geq \tau \\ S^{l}_{t}(i), & \text{otherwise} \end{cases}$$

**3. 主要方法类别**

| 类别 | 子类 | 代表工作 |
|------|------|----------|
| **垂直循环（激活基）** | 架构循环 | Universal Transformer, CoTFormer, Recursive Transformer, Recurrent-Depth |
| | 显式隐藏状态反馈 | Coconut（连续思维向量）, CODI（自蒸馏对齐）, CCOT（变长连续嵌入） |
| | 训练诱导循环 | Stepwise Internalization, MIDAS渐进堆叠, RELAY |
| | 压缩态循环 | VQ-VAE离散潜在token, Gist tokens |
| **水平循环（隐藏状态基）** | 线性态循环 | Linear Attention, Mamba-2, DeltaNet, HGRN-2, RWKV-6 |
| | 梯度态循环 | TTT（测试时训练）, Titans, ATLAS |
| **无限深度推理** | 掩码扩散模型 | LLaDA, SEDD, D3PM, dKV-Cache, DoT-SEDD |
| | 嵌入扩散模型 | Diffusion-LM, Plaid, TESS |
| | 混合AR-扩散模型 | DiffuLLaMA, Gemini Diffusion, Mercury |
| | 优化视角 | Infini-attention, TTT, LaCT（大块测试时训练） |

**4. 关键洞察**：
- 深度来源于**时间维度的优化**：隐藏状态充当"快速权重"层，越长的序列等价于更多的优化迭代
- 激活基方法和隐藏状态基方法的根本区别在于计算是沿着"深度"方向展开还是沿着"时间"方向展开
- 训练可以在标准Transformer架构上诱导出循环行为，无需架构修改

### 实验设置（数据集/模型/指标/结果表格）

本文为**综述论文**，不包含新的实验。论文明确指出："notably, this survey does not offer a direct empirical comparison across these varied models." 原因在于该领域发展迅速，各模型训练条件（预训练方式、模型规模、训练数据）不一致，且多数研究是与非推理LLM基线对比而非互相比较。

**研究中提及的关键基准数据集**（来自被引论文）：
- **数学推理**：GSM8K, MATH
- **规划任务**：Blocksworld, 多约束优化问题
- **长上下文**：1-shot recall, 百万级token流

**代表性结果的定性描述**（来自被引论文）：
- CODI（Shen et al.）首次在GSM8K上以潜在方法达到显式CoT的同等性能
- Titans-S（~250M参数）经过约100万优化步后，在1-shot recall上匹配1.3B Transformer的性能
- System-1.5推理在GSM8K上实现20倍以上的推理加速，同时保持CoT准确率
- dKV-Cache实现2-10倍推理加速，dLLM-Cache达到9.1倍加速

### 优势与局限

**优势**：
1. 提出了首个全面的潜在推理分类体系（垂直/水平/无限深度），为该快速发展的领域建立了统一的理论框架
2. 从理论上阐述了显式CoT与潜在CoT之间的联系（公式4 vs 公式5），揭示了带宽差距约2700倍
3. 系统性地覆盖了从架构设计、训练策略到可解释性的全链路研究脉络
4. 将扩散模型重新概念化为"空间无限推理"框架，统一了AR和扩散两种范式的推理机制
5. 提出了"深度来源于时间维度的优化"这一统一视角，连接了TTT、记忆压缩和固定点RNN

**局限**：
1. **无定量实验对比**：因各模型训练条件差异大，论文明确放弃对核心方法的实证性能比较，降低了作为综述的参考价值
2. 对多语言、多模态场景下的潜在推理涉及较少
3. 2025年7月提交，因领域发展极快，部分最新工作（如推理时计算扩展、强化学习与潜在推理结合）可能未覆盖
4. 论文作者数量庞大（32+位），结构虽完整但部分章节较浅

### 复现难点

本文为综述，不存在复现问题。但综述中引用的各主要方法均存在不同程度的复现挑战：
- **训练资源需求大**：多数方法需要从头预训练或大规模RL训练（如DiffuLLaMA需要将AR模型转换为扩散模型的持续预训练）
- **架构设计复杂**：Pre/Loop/Coda结构、自适应计算时间机制等需要定制化实现
- **训练稳定性**：如Infini-attention的复现尝试中发现压缩步数增加后性能下降，门控参数存在严重收敛问题
- **硬件要求高**：百万级token的TTT方法需要专门的大块并行化策略

### 对当前研究的启发

1. **潜在推理作为未来LLM推理的核心范式**：当前最强推理模型（DeepSeek-R1、Qwen3）已开始内化CoT，但论文指出真正的"latent reasoning"可能提供更高性能上限
2. **多语言推理的潜在桥梁**：论文指出潜在空间不受自然语言词汇表限制，这意味着潜在推理天然支持跨语言推理路径——可跳过翻译步骤直接在语义空间推理，对多语言安全对齐研究有重要意义
3. **可解释性的双刃剑**：潜在推理提升了表达能力但丧失了中间步的人脑可读性，需要发展新的机械可解释性工具（论文第4节）
4. **无限深度推理的新方向**：将扩散模型重新定义为"空间推理"范式，为结合AR的自回归生成与扩散的全局规划提供了理论依据
5. **测试时训练（TTT）作为推理深度扩展器**：论文统一视角显示"time for depth"是一种新的scaling方向
