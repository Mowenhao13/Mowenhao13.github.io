# Workflow 目录

> 本目录收集了用于**科研论文概念学习**的 AI Agent 工作流方法、范式和编排框架。

## 目录结构

```
workflow/
├── INDEX.md                          ← 本文件
├── paper-understanding/              ← 单篇论文理解工作流
│   └── README.md
├── literature-review/                ← 文献综述工作流
│   └── README.md
├── concept-evolution/                ← 概念演进追踪工作流
│   └── README.md
└── pipeline-orchestration/           ← Pipeline 编排工作流
    └── README.md
```

## 分类说明

| 分类 | 内容 | 适用场景 |
|------|------|----------|
| [paper-understanding](paper-understanding/README\.md) | 单篇论文深度理解方法 | 路径 A: 从当前论文学习新概念 |
| [literature-review](literature-review/README\.md) | 多篇论文综述和文献调研 | 路径 B: 综述论文/领域奠基性论文 |
| [concept-evolution](concept-evolution/README\.md) | 概念提出/比对/演进追踪 | 概念溯源和演进分析 |
| [pipeline-orchestration](pipeline-orchestration/README\.md) | 多阶段流水线编排 | 组合多个工作流步骤 |
